Drop CS2 map preview images here as <mapname>.png (lowercase), e.g.:

  de_dust2.png
  de_mirage.png
  de_inferno.png
  de_nuke.png
  de_ancient.png
  de_anubis.png
  de_vertigo.png
  de_overpass.png
  de_train.png

The server overview matches the live map name to a file here. PNG is preferred;
.jpg also works as a fallback. If no image is found, a colored gradient tile is
shown automatically (based on the map name), so this folder is optional.

Recommended size: ~640x360 (16:9), PNG.
