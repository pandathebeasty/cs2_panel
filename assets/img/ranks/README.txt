Rank images
===========

The competitive CS2 skill-group icons (Silver I .. The Global Elite) are bundled
here as SVG and are shown on the Ranks page and the dashboard top-players list,
for both stats backends (K4-Zenith and K4-System).

Files are named by the panel's rank slug:
  silver-1  silver-2  silver-3  silver-4  silver-elite  silver-elite-master
  gold-nova-1  gold-nova-2  gold-nova-3  gold-nova-master
  master-guardian-1  master-guardian-2  master-guardian-elite
  distinguished-master-guardian
  legendary-eagle  legendary-eagle-master  supreme-master-first-class
  global-elite      none

Accepted file types (first match wins): .png, .webp, .svg
If a file is missing, the panel falls back to a coloured CSS badge.

Premier rating badges
---------------------
When the stats rank style is set to "premier", the panel shows the CS2 CS Rating
number next to the official Premier badge, coloured by the official 7-band tier.
The badge art is picked per band from:
  premier-grey  premier-lightblue  premier-blue  premier-purple
  premier-pink  premier-red        premier-gold
(bands: grey 0-4999, lightblue 5000-9999, blue 10000-14999, purple 15000-19999,
 pink 20000-24999, red 25000-29999, gold 30000+). A generic premier.* is used if
 a per-band file is missing; if none exists, a coloured text pill is drawn instead.

The bundled premier-*.png badges are the official CS2 Premier rating plates, taken
from the css-bans panel (counterstrikesharp-panel/css-bans, public/images/ratings/
rating.common|uncommon|rare|mythical|legendary|ancient|unusual.png). Counter-Strike(R)
and these badges are the property of Valve Corporation.
